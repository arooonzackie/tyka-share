Phone Shell storyboard

All 17 screens of the web Shell design adapted for mobile.

Full-page Shell by default. Tap the terminal command line to open Android’s native keyboard. A compact row supplies Tab, Enter and Esc; the separate message box and Keyboard button are removed. Model, effort and context stay visible. Minimize reveals the app’s other options; expanding returns to the same session and draft. Mic and attachment access stay in the session menu. These images show the proposed design, not a completed implementation; the Android keyboard is illustrated.
