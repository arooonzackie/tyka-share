Phone Shell storyboard

All16 screens of the web Shell design adapted for mobile.

Design draft for review. Local and Tyka groups sit above the worker tabs. The input stays docked, with model, effort and context visible below. These images show the proposed interface, not a completed implementation.

SCREEN 1 OF16

Open Builder · read

Same session opens directly. Output pans inside terminal; composer and model, effort, context stay docked.

SCREEN 2 OF16

Local picker · return

Pick Claude Code or Codex and a folder. Close the picker to return to the selected Local session.

SCREEN 3 OF16

Tyka picker · return

Choose Builder or Shadow from Tyka menu. Dismissal returns to the selected managed session.

SCREEN 4 OF16

Worker menu · more tabs

Resume, Rename, settings, Restart fresh and Close. Rotation or maximize preserves selected session.

SCREEN 5 OF16

Type · keyboard open

Illustrative keyboard. Input and both metadata rows remain above it; output area shortens without overlap.

SCREEN 6 OF16

New worker · new profile

Name and model; start from a skill, file, or fresh session. Cancel returns to Builder.

SCREEN 7 OF16

Existing profile · none saved

New profile returns to panel 6; Cancel returns to Shell. Launch stays disabled with no profiles.

SCREEN 8 OF16

Session settings

Model and machine controls stay bounded. Machine change applies to next launch, with a note.

SCREEN 9 OF16

Confirm close · cancel path

Close stops this worker; saved conversation remains. Cancel returns to the same worker.

SCREEN 10 OF16

Disconnected · retry

Reconnecting disables input, preserves the selected session and offers Retry.

SCREEN 11 OF16

No workers · PC offline

First-use route offers Connect PC or New worker. Local input and context are unavailable offline.

SCREEN 12 OF16

Remote watch · approval needed

Request typing for this Claude worker; approval happens at the PC. Watcher panning preserves shared PTY size.

SCREEN 13 OF16

New worker · fresh session

Fresh starts without a source file. Create starts this worker in the shared Shell; Cancel returns to Builder.

SCREEN 14 OF16

Existing profile · launch

Choose a saved profile and launch. Cancel returns to Builder; launch selects the new worker in this Shell.

SCREEN 15 OF16

Question sheet · Claude worker

Choose an answer or dismiss to return to the same worker. Sample only; runtime support is not asserted.

SCREEN 16 OF16

Worker created · ready

Create from panel 13 or Launch from panel 14 lands here. Cancel on either form stays on the previous session.
