Phone Shell storyboard

All 17 screens of the web Shell design adapted for mobile.

Full-page Shell by default. A visible Minimize button reveals the app’s other options. Expanding returns to the same session and draft. Local and Tyka groups sit above worker tabs, with the input docked and model, effort and context visible below. These images show the proposed design, not a completed implementation.

First-use route offers Connect PC or New worker. Local input and context are unavailable offline.

SCREEN 14 OF 17
